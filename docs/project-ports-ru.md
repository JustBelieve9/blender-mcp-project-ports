# Установка и два независимых проекта

MCP Project Ports — модификация официального Blender Lab MCP. Требуется Blender 5.1 или новее.
Проверяемая версия аддона: 1.1.0. Лицензия GPL-3.0-or-later, авторство Blender сохранено.

## Установка

1. Скачай `mcp-1.1.0.zip` из раздела Releases этого репозитория.
2. Сохрани копию прежнего MCP и настроек Blender для отката.
3. Выключи прежний MCP. Убедись, что из другого репозитория расширений не включена его вторая копия.
4. В Blender открой Preferences → Get Extensions → меню → Install from Disk и выбери ZIP.
5. Включи MCP Project Ports. При установке в другой extension repository старую версию оставь выключенной.
6. В 3D View нажми N и выбери вкладку MCP.

ID расширения остался `mcp`. Модификация заменяет исходную версию в выбранном repository;
одновременно включать их из двух repositories нельзя: идентификаторы операторов совпадают.
Обновление MCP из Blender Lab может перезаписать модификацию.

## Два проекта

1. Открой `A.blend` и `B.blend` в **двух отдельных процессах Blender**.
2. В A выбери Host `127.0.0.1`, Port `9876`, нажми Start MCP Bridge Server и сохрани `.blend`.
3. В B выбери Host `127.0.0.1`, Port `9877`, запусти сервер и сохрани `.blend`.
4. Убедись, что в каждой панели написано Running и указан свой `Listening` endpoint.

Все сцены и окна одного процесса используют один порт проекта. Окна одного процесса не являются отдельными проектами.
Чтобы сменить работающий порт, нажми Stop, отредактируй Port и снова Start.
Если порт занят, выбери другой вручную. Аддон не ищет свободный порт автоматически.
Скопированный `.blend` сохраняет прежний порт; для одновременной работы копии нужен новый порт.

Настройка хранится в локальных Scene внутри `.blend`, согласованно для всего файла.
Linked Scene и library overrides не меняются. Если после объединения сцен обнаружены разные настройки,
выбери нужные значения в панели и нажми Apply Settings to Project.

## Подключение агентов

Сам аддон не является MCP-сервером для клиента: нужен отдельный официальный Python-пакет из папки `mcp` этого репозитория.
Не подставляй вместо него одноимённый сторонний пакет с PyPI.

Например, в PowerShell из корня скачанного репозитория:

```powershell
uv venv .venv
uv pip install --python .venv/Scripts/python.exe -e ./mcp
```

В конфигурациях из `examples/` замени `C:/path/to/blender-mcp-project-ports` на абсолютный путь к своей копии.
Агенту A дай конфиг `agent-project-a.json`, агенту B — `agent-project-b.json`.
Каждый содержит единственное назначенное подключение; просто добавить два сервера в общий список недостаточно для изоляции агентов.
Формат `mcpServers` поддерживают многие клиенты, но конкретному приложению может требоваться другой синтаксис.

Параметры соединения с Blender передаются **в окружение процесса MCP-сервера**:

```json
{"BLENDER_MCP_HOST": "127.0.0.1", "BLENDER_MCP_PORT": "9876"}
```

Кнопка Copy Connection Settings копирует именно эти переменные, а не готовый конфиг приложения.
Для B используй `9877`. Аргумент `blender-mcp --port` относится к HTTP-транспорту и не выбирает порт аддона.

Перед изменениями каждый агент должен через `execute_blender_code` проверить проект:

```python
import bpy, os
result = {"filepath": bpy.data.filepath, "pid": os.getpid()}
```

Сверяй путь с назначенным `.blend`. Несовпадение — причина остановиться и исправить подключение.
Порт маршрутизирует запросы, но не подтверждает постоянную идентичность файла.
Инструменты с суффиксом `_for_cli` отдельно открывают файл в фоновом Blender и не заменяют управление живым проектом.

## Сохранение и автозапуск

Настройки начинают сохраняться после редактирования в панели или ручного Start. Сохрани `.blend`, чтобы удержать их на диске.
Глобальные Default Host/Port в Preferences используются только для файлов без проектных настроек.

По умолчанию проектный автозапуск выключен. Чтобы включить его, отметь Auto Start This Project и сохрани файл.
Также должен быть включён глобальный Auto Start в Preferences; требуется разрешённый Online Access.
Несохранённые файлы и startup-шаблон без filepath автоматически сервер не запускают.
Ручной Stop отменяет ожидающий автозапуск до следующей загрузки файла.

При открытии другого `.blend` старый listener закрывается до загрузки данных.
Настроенный новый проект может затем запустить собственный порт по своим флагам.
После ошибки загрузки сервер остаётся остановленным: проверь проект перед ручным Start.

Фоновый CLI сохраняет прежнюю семантику: `--command blender_mcp --host ... --port ...` использует явные параметры,
без них — исходные defaults `localhost:9876`. Проектные настройки файла CLI не переписывает.

## Откат

Закрой Blender, сохрани копию модифицированного аддона и `userpref.blend`.
Установи сохранённый официальный ZIP в тот же repository или верни его папку из резервной копии.
Оставь включённой только одну версию MCP. Проектные свойства в `.blend` не мешают исходному аддону;
исходная версия их не использует и берёт порт из общих Preferences.
